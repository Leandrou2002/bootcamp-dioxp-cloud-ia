# 1️⃣ Acesse o Portal do Azure

* Vá até [https://portal.azure.com](https://portal.azure.com)
* Esta tela será exibida se não houver uma conta conectada:

<figure><img src="../.gitbook/assets/tela de login.png" alt=""><figcaption></figcaption></figure>

* Caso não possua cadastro Microsoft/Azure clique no texto "Crie uma!" que está destacado e crie sua conta informando os dados que serão requisitados
* Faça login com sua conta Microsoft
* Logo após você será redirecionado(a) e verá o **Dashboard** do Azure.

<figure><img src="../.gitbook/assets/Dashboard Azure.png" alt=""><figcaption></figcaption></figure>
